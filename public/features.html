Platform Features & Capabilities

Nabhangan Engineers — Project & Workflow Tracker

This platform is a SaaS product developed and owned by Chemiligence Solutions, licensed for use by Nabhangan Engineers. It is a purpose-built digital workflow system for property valuation and site survey management — tracking every case from initial lead through survey, drafting, checking, printing, scanning, and final dispatch, with role-based access ensuring each team member sees only what is relevant to them.

👤
Owner / Administrator
Dashboard & Overview
  • Live case count across all 8 workflow stages
  • Realtime Occupancy — shows staff on currently active work only
  • Third-party surveyor tracking with active link status
  • Greeting personalised to Indian Standard Time
  • Quick navigation to all admin modules
Case Management
  • Create new cases with bank, owner & property details
  • Add custom survey fields per case at the lead stage
  • Edit all case information at any time
  • Delete cases (admin only)
  • Mark documents as pending with visible warning
  • Approve cases flagged for review
Staff Assignment
  • Assign any staff member to any of the 8 workflow stages
  • Visual assignment matrix — all cases × all staff at a glance
  • Remove assignments from the matrix directly
  • Assign non-project "Other Tasks" to any staff member
  • Generate secure third-party survey links (see below)
Stage Control
  • Advance case to the next stage once current stage is complete
  • Revoke a submitted stage and send it back for correction
  • Auto-advance when third-party survey is submitted
  • Visual progress stepper showing current position
Activity & Timeline
  • Activity History: files, time logs & third-party submissions per stage
  • Project Timeline: assigned staff, hours, and submission timestamps
  • Lead creation date shown in timeline
  • All timestamps in Indian Standard Time (IST)
  • Download Timeline as CSV
Reports & Documents
  • Site Survey Report — printable PDF with Nabhangan logo
  • Covers bank info, owner, property, site visit, GPS, dimensions, valuation
  • Custom project fields printed as an additional section
  • Site photos embedded in report (up to 10)
  • Signature strip and copyright footer
Admin Modules
  • Staff directory — add, edit, activate / deactivate staff
  • Assignments panel — stage-wise allocation for all active cases
  • Other Tasks — assign non-project work to staff
  • Task Requests — approve or reject staff-raised requests
  • Reports module for business analytics
Account & Security
  • Secure login with Supabase authentication
  • Change password with current password verification
  • Role-based access — admin sees all, staff sees own work
  • Session-protected routes; unauthenticated access redirected
👷
Staff Members
Personal Dashboard
  • View all cases currently assigned to them
  • Total hours logged across all cases
  • Attendance summary for the current month
  • Pending task requests at a glance
  • Greeting personalised to IST time of day
Case Work
  • Access assigned case detail page
  • Fill and submit site visit report (Survey stage)
  • Custom survey fields specific to each case
  • Upload work files (photos, documents) to a case
  • Log hours spent on each stage
Survey Form
  • Full site visit data entry form
  • One-tap GPS location capture
  • Photo uploads (up to 10 per case, max 5 MB each)
  • Save draft and return later
  • Final submit locks the form
Attendance & Requests
  • Mark daily attendance (present / absent / half-day)
  • View attendance history for the current month
  • Submit task requests to admin
  • Track status of submitted requests
Account
  • Self-service password change
  • Current password verified before update
  • View own profile details
Visibility
  • Can view case progress and Activity History
  • Can download Site Survey Report PDF
  • Cannot edit case details or delete cases
  • Cannot see other staff's assignments or admin modules
🔗
Third-Party / External Surveyor
Secure Link-Based Survey Submission
  • Admin generates a one-time secure link with configurable expiry (6 h to 72 h)
  • External surveyor accesses the form directly — no login or account required
  • Full site visit form including any custom fields defined for that case
  • One-tap GPS location capture on mobile
  • Photo uploads directly from the field
  • Draft auto-save — surveyor can return and continue before submitting
  • On final submit: case automatically advances to Rate Verification stage
  • Link becomes invalid after submission; used-at timestamp recorded
  • Surveyor name and submission time visible in Activity History and Project Timeline
